## Release & Update Workflow

1. Attach the signed APK named **`VORTEX.apk`** to a new [GitHub Release](https://github.com/adhi2k/VARTEX/releases).
2. Increment `versionCode`, `versionName`, and `changelog` inside [`version.json`](version.json) on the `main` branch.
3. Users tapping **CHECK FOR UPDATES** inside **VORTEX Control Center** will automatically see the new version prompt and download link.
